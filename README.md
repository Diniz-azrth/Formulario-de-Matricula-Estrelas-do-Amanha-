# 🎓 Formulário de Matrícula - Estrelas do Amanhã
Este é um projeto de interface web desenvolvido para o processo de matrícula de uma escola de educação infantil fictícia. O objetivo principal foi criar um formulário completo, responsivo e visualmente agradável, aplicando boas práticas de marcação HTML e estilização CSS.

---

## 🚀 Tecnologias Utilizadas
Este projeto foi construído utilizando apenas tecnologias web básicas:

HTML5: Estruturação semântica do formulário e dos campos de dados.

CSS3: Estilização da interface, incluindo:

Layout responsivo.

Uso de Flexbox para organização de elementos.

Customização de formulários (inputs, textareas, checkboxes e radio buttons personalizados).

Importação de fontes via Google Fonts.

---

## 💡 Principais Aprendizados
Como este é o meu primeiro projeto, este desenvolvimento foi fundamental para consolidar conhecimentos em:

Estruturação de formulários: Como organizar informações de forma lógica usando fieldset e legend.

Responsividade: Adaptar o layout para diferentes tamanhos de tela.

Design Web: Uso de elementos visuais (ícones e ilustrações) para criar uma experiência de usuário (UX) mais acolhedora.

Boas práticas de organização: Divisão de pastas entre styles e assets para manter o código limpo.

---

## 📦 Como rodar o projeto
Clone este repositório em sua máquina:

Bash
git clone https://github.com/Diniz-azrth/Formulario-de-Matricula-Estrelas-do-Amanha-
